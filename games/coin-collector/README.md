# 🪙 Coin Collector

## 📖 Descripción

**Coin Collector** es un videojuego arcade desarrollado como parte de mi aprendizaje en Game Development.

El objetivo principal es controlar al personaje y recoger todas las monedas del escenario antes de que se termine el tiempo.

---

## 🎯 Objetivo

El jugador debe recoger las **5 monedas** distribuidas por el escenario en un máximo de **30 segundos**.

Si consigue todas las monedas, gana la partida.

Si el tiempo llega a cero antes de recogerlas todas, pierde.

---

## 🎮 Género

**Arcade**

---

## 🕹️ Controles

| Tecla | Acción |
|---|---|
| W | Mover arriba |
| A | Mover izquierda |
| S | Mover abajo |
| D | Mover derecha |
| 🔄 Reiniciar | Reiniciar partida |

---

## 🪙 Características

- Movimiento del jugador.
- Sistema de monedas.
- Detección de colisiones.
- Sistema de puntuación.
- Temporizador de 30 segundos.
- Sistema de victoria.
- Sistema de Game Over.
