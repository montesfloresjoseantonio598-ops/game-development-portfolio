# 🧮 Math Quest: Aventura Aritmética

## 📖 Descripción

Math Quest es un videojuego educativo interactivo desarrollado para estudiantes de 1ro de secundaria como parte del curso de Game Development. 

El objetivo principal es resolver operaciones aritméticas (sumas, restas, multiplicaciones y divisiones) de forma entretenida a lo largo de 10 retos.

## 🎯 Objetivo

* Responder correctamente las **10 preguntas** de opción múltiple.
* Cada respuesta correcta suma **1 punto**.
* Al finalizar el juego se mostrará la calificación total obtenida sobre **10**.

## 🎮 Género

Educativo / Trivia Arcade

## 💻 Tecnologías

* HTML5
* CSS3
* JavaScript
